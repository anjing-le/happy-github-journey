# Happy GitHub Journey

把项目与文章拆成关键设计、技术与原理的静态学习站。当前已有一份真实图文初稿，具体解析粒度仍待用户校准；最佳实践输出仍在规划中。

- 网站：[happy-github.anjing.cc](https://happy-github.anjing.cc/)
- 公开仓库：[anjing-le/happy-github-journey](https://github.com/anjing-le/happy-github-journey)
- 之前的结构预览保存在 Git 历史中。

## 本地构建

需要 Node.js 18 或更新版本。无第三方依赖。

```bash
npm run build
```

站点源码在 `site/`，内容权威在 `content/` 的 Markdown。构建先校验资料与关联，再复制界面源码并生成 `dist/catalog.js` 和 `dist/catalog.json`，为样式、脚本与内容依赖添加内容哈希版本。界面使用原生 HTML、CSS 和 JavaScript，无第三方运行时依赖；勿手改生成文件。

## 图文存档工具

Skill 自带 Python 工具，支持公开微信 URL、经核实的公开转载页和已有网页 HTML 导入，流程见 [图文获取与存档](skills/anjing-happy-github-journey/references/wechat-capture.md)。它保存实际取得的 HTML、正文、离线阅读文件、图片和校验清单；遇验证页返回失败，有图片缺失则记录缺失，不修改解析状态或自动宣称完整。

原链接不可读时，Codex 主动查找原作者同步版或明确列出原出处的公开转载；搜索引擎缺少结果时可补充公开站内搜索。此次转载获取、图文保存和校验均由 Codex 完成，无需用户手动导出或安装新扩展。已有正常取得的网页也可导入；工具的 Python 依赖不进入静态网站。
