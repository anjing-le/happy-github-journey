MCP 是 Model Context Protocol 的缩写。可以把它理解为 AI 应用和外部能力之间约定好的接口语言：服务端公布有哪些工具和资源，客户端发现后按规定传参调用。

例如，把查订单的能力接成 MCP 工具，支持该协议的助手就能接入。协议统一了连接方式；业务权限、参数校验和操作是否成功，仍需要服务本身处理。
