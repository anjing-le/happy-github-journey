Git Hooks 像版本管理里的自动检查点：提交或推送等操作发生时，Git 在指定时机运行脚本，可以检查格式、测试或提交信息。

它减少开发者忘记检查的机会，但本地钩子需要安装，也存在可绕开的路径。团队需要强制执行的要求，通常还要在共享仓库或持续集成流程中落实。
