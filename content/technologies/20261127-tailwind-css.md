Tailwind CSS 提供一组小型样式类，分别表达间距、字号、颜色、布局等。写页面时组合这些类，就能描述一个元素该怎样显示，不必为每个小变化另起一个样式名称。

它方便快速迭代和统一常用取值，也常用于生成式界面。它负责样式表达，不会自动决定页面布局是否合理、交互是否完整或设计是否好看。
