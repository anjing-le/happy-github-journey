Git worktree 允许在不同目录里检出同一仓库的不同分支。例如一处继续开发功能，另一处修复线上问题，无需来回收起未完成的文件。

它也适合隔离多个 Agent 的代码任务。不过目录分开只减少文件互相覆盖，不能避免方案冲突；合并、测试和审查仍需统一安排。
