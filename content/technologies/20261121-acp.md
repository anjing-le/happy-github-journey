ACP 是编程 Agent 和客户端之间的一套通信约定。客户端可以用它启动会话、发送消息、展示执行过程，并处理 Agent 发来的权限请求。

它解决的是客户端怎样接入 Agent；MCP 主要解决 Agent 怎样接入工具和数据，两者关注的接口不同。采用同一协议也不代表每个 Agent 支持完全相同的能力。
