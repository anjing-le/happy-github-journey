Function Calling 是模型与程序之间的一种接口约定：程序描述可用工具和参数，模型选择工具并生成参数，真正的执行由程序完成。例如用户说“查一下昨天订单”，模型可以提交日期明确的订单查询请求。

它让对话接上真实系统，但生成参数不等于获得权限或执行成功。程序仍需校验参数、检查授权，并把实际结果返回给模型。
