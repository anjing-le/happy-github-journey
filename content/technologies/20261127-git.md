Git 用来记录文件的变化历史，代码和 Markdown 文档都可以管理。每次提交形成可识别的版本，分支可以隔离正在尝试的修改，再经过比较与评审合入主线。

对于 Agent，Git 既能固定调查时依据的代码，也能检查生成前后的差异、恢复旧内容。提交记录证明保存了哪些变化，不能单独证明变化正确或已经部署。
