Docker 把程序及所需依赖做成镜像，再从镜像启动容器。例如为代码任务准备固定版本的 Python 和测试工具，每次都创建一个新的执行环境。

容器比为每个任务准备完整系统更轻量，但通常共享宿主机内核。文件挂载、用户权限和网络配置仍会影响隔离范围。
