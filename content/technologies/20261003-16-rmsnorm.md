RMSNorm 先对一个 token 的特征求平方均值，用每个特征除以这个均值加上保护项后的平方根，最后乘可学习的逐维权重。保护项是一个很小的数，用来避免数值问题。

它不需要其他 token 的数据，可以逐 token 独立完成。但计算平方均值时，仍要把这一行的多个值求和。

所以 token 数量增加，本不该改变某个 token 的输入；若实现因此换了行内线程数或求和分段，该 token 的浮点结果仍可能变化。
