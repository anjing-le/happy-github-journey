React 是用组件组织界面的 JavaScript 库。可以把消息列表、输入框和工具结果各写成一个组件，给它们数据和状态，再组合成完整页面。

它适合交互较多、需要反复复用界面能力的产品。组件库可以替你处理不少显示逻辑，但后端调用、权限与数据保存仍需要另外接好。
