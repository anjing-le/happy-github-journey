Agent Skill 可以理解为给 AI 的一份专项工作手册：说明什么时候用、按什么步骤做，并附上需要查的资料或执行的脚本。它通常以包含 SKILL.md 的目录保存，方便版本管理和复用。

支持它的运行环境先看名称和描述，任务需要时再读详细说明。Skill 提供知识和流程；实际可调用什么工具、能访问什么数据，仍由运行环境的权限决定。
