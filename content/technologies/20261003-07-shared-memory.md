共享内存是 GPU 上由程序组织使用的小型高速存储，同一线程块内的线程可以共同访问。

它适合保存一组线程都要使用的数据，让线程协作加载后重复读取，而不用各自反复访问显存。

矩阵乘法分块时，可以把 A、B 的小块放进共享内存。加载者和使用者之间需要同步，避免数据还没准备好就开始读取。
