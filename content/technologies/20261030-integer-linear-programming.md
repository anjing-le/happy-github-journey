整数线性规划把决策写成可以求解的数学问题。例如用 0 或 1 表示某件商品是否放进橱窗，再规定每个位置能放几件、同一商品最多出现几次，目标是让总得分尽量高。

它适合排班、资源分配和组合选择。求解得到的最优只针对给定的候选、评分和约束；评分不能代表真实效果时，数学上最优的组合也未必带来最好的业务结果。
