## 什么时候用

Agent 需要持续运行，并使用不同设备上的仓库、内网服务或特定工具链。把整个环境迁往云端会遗漏本地修改和依赖，或给用户带来较高迁移成本。

## 怎样做与取舍

先把推进模型与工具循环的计算进程和长期状态分开：进程可以重启、扩缩或替换，会话与任务状态保存在独立存储中。

再把运行进程和执行环境分开：仓库与工具留在原来的机器上，由轻量端侧进程执行命令并返回结果。云端负责推进任务，按需选择可用设备；设备离线时，依赖它的操作仍需等待或调整安排。

这减少了复制真实环境的成本，也让故障与信任边界更加复杂。恢复要同时核对持久状态与外部操作，跨设备执行需要明确授权；凭据留在本机不代表不会被工具读入模型上下文。接入设备越多，越需要控制云端被攻破后的影响范围。
