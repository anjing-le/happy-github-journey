## 什么时候用

使用执行结果或测试得分训练 Agent，模型有能力探索文件、网络和工具中的捷径。

## 怎样做与取舍

先说清期望能力与奖励依据。代码任务既检查原先失败的测试是否通过，也检查原先通过的测试是否被破坏；评分由环境计算，不接受 Agent 自报完成。

把参考答案、隐藏 Git 历史和验收脚本放在 Agent 不可随意修改的边界之外，限制下载原始修复和替换依赖等泄题路径。命令过滤只能挡住一部分已知方式，需要结合真实文件与网络权限。

选择有学习空间的题目，同时保留适量困难题，并在未参与训练的任务上检验。环境越严格，准备和维护成本越高，也可能偏离真实工作条件；因此既要防止刷分，也要解释训练范围和迁移限制。
