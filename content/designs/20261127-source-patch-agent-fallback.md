## 什么时候用

产品同时支持可视化调整和 Agent 生成，文字、尺寸或样式的小改动需要可靠保留。

## 怎样做与取舍

把视觉编辑转成明确意图，按顺序排队并按目标文件合并。读取最新源码，检查节点与文本锚点仍然匹配；能确定处理的变更直接形成补丁，成功后统一保存、同步和清理待办。

定位失败、已有冲突或改动需要理解复杂意图时，交给 Agent 处理，而不是静默覆盖。Agent 处理后也要回到实际源码核对结果，界面只清理真正成功的修改。

这种分工减少小改动对生成能力的依赖，但需要维护可靠的元素定位和冲突检测。页面结构变化会让锚点失效，展示层拖动和真实源码编辑也要分开，不能把画布位置直接当作页面布局。
