## 什么时候用

Agent 需要多轮修改、异步评测或操作业务系统，而成功条件、预算和退出规则可以明确表达。

## 怎样做与取舍

把候选版本、运行结果、失败类别和次数落入持久状态。语义归纳交给模型；指标计算、阈值比较和状态迁移交给代码。失败按原因回到不同步骤，必要时退回良好版本或交给人，而不是无限重试。

这样能核对“谁做了什么、为何继续”。代码只能保证按既定规则执行，规则本身是否正确、样本是否代表真实业务，仍需验证。
