## 什么时候用

Agent 长期参与重复业务，既需要恢复单个任务，也希望从多次交付中积累经验。

## 怎样做与取舍

执行期间在项目记忆中维护需求、方案、进展、评审和验收依据，与代码变更保持关联。它服务当前任务的恢复，不要求每段内容都成为长期规则。

结项时筛选：稳定且已确认的业务知识进入长期 Wiki；反复暴露的流程问题成为 Skill 或提示词的修改候选；原始日志和阶段性信息留档。知识和流程分别由对应责任人确认后发布。

保留项目记录可以追溯经验来自哪里，筛选则避免长期入口被噪声淹没。一次成功或失败还不足以证明通用规则，迁入时要保留成立条件，并检查是否与既有知识冲突。
